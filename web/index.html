Population profiles and scheduling rules

Morning: 06:30-12:00 / Afternoon: 12:00-17:00 / Night: 17:00-22:00 / Whenever: any available time.

Flexibility extends the preferred start period by 0, 1, or 3 hours, or allows any available start. The entire one-hour workout must fit inside an availability window. Under the utility rule everyone pays a crowding penalty that grows as the forecast nears capacity; crowding taste only shifts preferences below capacity.

Changing a setting other than the population seed or mix keeps the same agents. A new population seed creates a different assignment.
